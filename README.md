# Our OS

A personal operating system app — one codebase for web, Android, iOS,
Windows, macOS and Linux. Built with Flutter + Dart.

This is the app that replaces a personal Notion hub ("My OS's", 22
systems built in early 2023) with a personal, open-source app you own.

## What is inside

- All 22 systems, preloaded: Core (Project, Tasks, To-do list,
  Knowledge Bank, Course & Series Tracker, My Relationship), Life
  (health, annual review, finances, plans, resources, interest-free
  loan, Mass OS, Play Store Purchases), Social Media OS (Games,
  Podcast, YouTube, Facebook, Instagram), Book Note OS (Non-fictional,
  Fictional).
- Add a new OS anytime, edit or delete any system.
- Inside each system: add, edit, check off and delete items, with
  title, status (To do / Doing / Done), tag, date, link and notes,
  plus search and status filters.
- Data stays on the device (SharedPreferences, plain JSON).
  Backup screen: copy the JSON out, or paste a backup back in.
  **Do not commit a backup file to this repo** — it is private data.
- No server, no account, no tracking. Open source, GPL-3.0.

## How this repo is organised

This repo contains the **source only** (`lib/`, `pubspec.yaml`,
`test/`, docs). The platform folders (`android/`, `ios/`, `web/`,
`windows/`, `macos/`, `linux/`) are generated by Flutter itself —
locally with `flutter create`, and in GitHub Actions by the workflow
below. That keeps the repo clean and avoids committing generated
icons, Gradle wrappers and other binary files.

## Run it locally

```bash
# 1. Install Flutter: https://docs.flutter.dev/get-started/install
flutter --version

# 2. Create a project, then use this repo's code in it
flutter create --project-name our_os our-os-app
cd our-os-app
cp ../our-os/lib/main.dart lib/main.dart
cp ../our-os/pubspec.yaml pubspec.yaml
cp ../our-os/analysis_options.yaml analysis_options.yaml
flutter pub get

# 3. Run it
flutter run -d chrome     # web
flutter run -d android    # Android phone / emulator
flutter run -d windows    # Windows PC
# iOS needs a Mac: flutter run -d ios
```

## Build each format

```bash
flutter build web            # build/web  -> GitHub Pages
flutter build apk --release  # build/app/outputs/flutter-apk/app-release.apk
flutter build appbundle      # Play Store bundle
flutter build windows        # build/windows/x64/runner/Release/
flutter build macos          # macOS app (on a Mac)
flutter build linux          # Linux binary
flutter build ipa            # iOS (on a Mac, Apple signing required
                             # for installing on a real iPhone)
```

## GitHub Actions

`.github/workflows/build.yml` runs on every push to `main`:

1. Checks out this source-only repo.
2. Runs `flutter create` to generate the platform folders.
3. Copies this repo's `lib/main.dart`, `pubspec.yaml` and
   `analysis_options.yaml` into the generated project.
4. Runs `flutter analyze`, then builds web + Android APK, and uploads
   them as artifacts (`our-os-web`, `our-os-apk`).

Download the APK from the Actions run's Artifacts section — that is
the installable Android build. The web artifact can be hosted on
GitHub Pages.
